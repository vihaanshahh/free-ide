Security and privacy

The folder stays on your computer.

The model key stays on the server. A client cannot mint tokens. Prompts and replies are logged so the operator can review usage. Passwords and API keys are not.

Keys stay on the server

The OpenRouter key and the Gravity key are server configuration. They are not in the landing page, the desktop bundle, or client error text.

Ads cannot be faked from the client

A body field such as tokens or credit is ignored. The server adds tokens only after it verifies the ad impression.

What is logged

The model, a truncated prompt and reply, token counts, latency, ad impressions, and errors. Passwords and API keys are not. The log is for review, not for training.

No training on your project

Paths, secrets, and source are stripped before an ad request. The workspace is not uploaded as a training set.
