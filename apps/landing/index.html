How it works

Four steps. Then the file changes.

  1. 01

    An ad unlocks the tokens

    Flash answers. A sponsored card under the reply pays for it. At 15 million tokens the reply slows. It does not ask you to upgrade.

  2. 02

    A real editor

    code-server, branded subspaces.si. It opens a small invoicing API so you can edit immediately.

  3. 03

    The agent edits the file

    Ask it to change src/routes/invoices.ts. opencode reads the file and applies the edit.

  4. 04

    The card stays under the reply

    The sponsored unit sits below the answer. Another can fill the explorer. Empty fill renders nothing.

The product

Free on purpose.

No subscription

No Pro tier and no frontier-model upsell. Steady chat, paid for by ads.

Code - OSS

code-server v4.141.0, named subspaces.si, opened on a sample API.

Flash only

glm-5.3-flash, with deepseek-v4.1-flash if the first call fails. Paths and secrets are stripped before any ad request.

Sponsored card

A card under the reply, and a slot in the explorer. Test mode is the default.

15M soft cap

The ledger counts tokens and slows replies at the cap. It does not block, and it does not bill you.

One command

Unpack the archive and run ./start. Node.js 22 fetches the pinned opencode binary.

FAQ

Short answers.

Is it really free?

Yes for the person using it. Ads cover a Flash model. There is nothing to subscribe to.

Where do downloads come from?

A public GitHub Release. The buttons use that host directly. The archives do not pass through this page.

What do I need to run it?

Node.js 22. Unpack the archive and run ./start. On macOS, if Gatekeeper blocks it, run xattr -dr com.apple.quarantine . in the unpacked folder. Keys go in a local .env only if you have them.

What is the ad?

A Gravity unit under the assistant reply. Without a key, a local card fills the slot.
