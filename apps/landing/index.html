How the free beta works.

The hosted chat starts with a small trial balance. Sponsored cards appear when an ad fills.

  1. Free

    subspaces.si is free

    There is no checkout and no Pro tier. A reply does not charge you.

  2. Card

    A sponsored card may appear under a reply

    Ad fill varies. The editor and CLI also have a local demo mode.

  3. Beta

    Ad rewards are paused

    Rewards will return when the ad provider can confirm an impression to the server.

  4. ≥ 0

    The balance never goes negative

    When the tokens run out, the reply waits. It does not bill you.

  5. Fit

    Ads are context-relevant via Gravity

    Gravity matches the card to the conversation. Paths, secrets, and source are stripped first.

Free AI should not end in a checkout.

The usual free plan is a trial. It asks you to upgrade, or it takes the code. We are changing that deal.

  1. 01

    No checkout

    The hosted trial is free. Sponsored cards support the beta.

  2. 02

    A server-controlled balance

    The hosted trial ends when its balance is spent. Local demo sessions have a separate soft cap.

  3. 03

    Your code is not the price

    The editor works on your computer. Ad requests receive a short excerpt with common code, path, and secret patterns removed.

  4. 04

    The answer has to land in the file

    Free chat usually ends in a box. Here the edit is written into the file, and you can undo it like any other change.

One command

Short answers.

Is it really free?

The beta has no subscription. Hosted chat includes a small trial balance; local demo mode remains available.

What do I need to run it?

Node.js 22. Unpack the archive and run ./start. On macOS, if Gatekeeper blocks it, run xattr -dr com.apple.quarantine . in the unpacked folder. Keys go in a local .env only if you have them.

What is the ad?

A Gravity unit under the assistant reply. Without a key, a local card fills the slot.
